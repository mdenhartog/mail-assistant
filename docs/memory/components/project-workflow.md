# Mail Assistant — Project Workflow

Generated by `/sdlc:setup` on 2026-11-08. Governs every `/sdlc:feature` run. Update by re-running `/sdlc:setup` (reconfigure) and superseding the affected ADRs.

## Phase table

| Phase | Name | What runs | Output → where | Who approves |
|---|---|---|---|---|
| 1 | Intent & brainstorm | `sdlc:intent` + `superpowers:brainstorming` | `docs/specs/<feature>.md` draft | — |
| 2 | Spec & threat model | `sdlc:spec-decomposition` + `sdlc:threat-model` + `sdlc:secure-by-design` | `docs/specs/<feature>.md` finalised, `docs/security/<feature>-threat-model.md` | **Marco** (spec + threat model) |
| 3 | Design & ADRs | `sdlc:archify` for architecture; `ui-ux-pro-max` + `design-tokens-bridge` for UI (per-feature prototype decision); `sdlc:decision-gate` for new choices | ADR files in `docs/memory/decisions/`; design tokens in `packages/tokens` (first UI feature) | **Marco** (ADRs + design) |
| 3a | Prototype *(per feature)* | `sdlc:clickable-prototype` when spec decides yes | Prototype artifact in Claude Design; link in spec | **Marco** |
| 3b | Integration contract *(first use)* | `sdlc:api-integration` for Gmail / Google Calendar | OpenAPI contract, mock server, guardrail confirmed | **Marco** |
| 4 | Unit planning | `sdlc:spec-decomposition` → unit list | `docs/plans/<feature>.md` | — |
| 5 | Build (TDD) | `sdlc:backend-dev` / `sdlc:frontend-dev` per unit, test-first | Code + tests in worktree | — |
| 6 | Challenge | `sdlc:red-team` + `sdlc:code-reviewer` | Findings; bugs as failing tests | — |
| 7 | Verify | `sdlc:verify` (guardrails, tests, coverage, audit, type checks) | Green CI | — |
| 8 | PR & merge | `superpowers:finishing-a-development-branch` → PR to `main` on GitHub | PR reviewed + merged | **Marco** |
| 9 | Release | GitHub Actions `release.yml` → release-please → GHCR image → Helm chart bump → Argo CD sync | Running on Kubernetes | — |
| 10 | Production signals | `sdlc:production-signals` — Sentry errors, Grafana metrics, Playwright synthetics daily, LLM evals daily | Alerts and dashboard | — |
| 10b | Bug agent (fix mode) | `sdlc:bug-loop` — 48 h watch window, 3 attempts, max 3 open PRs | Fix PRs | **Marco** |
