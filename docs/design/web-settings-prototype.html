    How to try this prototype
    1. Time zone: click the Time zone field and type "Bang", "Portugal", "UTC+7" or "Phuket" (nothing found). Use the arrow keys, Enter, Escape (twice to put the saved zone back).
    2. Pick Bangkok, then look at the preview line. Press Save changes to see Saving and Saved.
    3. Validation: set the Daily overview to 23:00 (inside quiet hours 22:00 to 07:00) and press Save changes.
    4. Conflict: change From to 22:30, press the Telegram simulation button below, then press Save changes. Choose Use mine or Keep Telegram's and save again.
    5. Sign out leads to the sign-in page; Continue with Google returns to the settings.
