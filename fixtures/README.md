# Fixtures and test accounts

- Seed data for local use and e2e lives in this folder (one file per domain) and is loaded by a seed script.
- Test accounts (after the identity decision) are listed here with role and purpose; passwords are local test values only and come from `.env`.
- Never production data or real personal data. GAMP 5 test data sets are versioned here too and checksummed by the evidence collector.
